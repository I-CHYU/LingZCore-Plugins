# 灵域智核 · 官方插件仓库 (LingZCore Plugins)

欢迎来到 **灵域智核 (LingZCore)** 的官方插件仓库！

灵域智核是一款运行在 Windows 上的本地 AI 编程工作站。通过安装插件，你可以无限扩展它的能力边界。

## 📦 如何使用插件？

**推荐方式：直接通过软件安装**
1. 打开灵域智核客户端。
2. 进入「设置」->「插件市场」。
3. 在列表中点击你需要的插件，选择「安装」。
4. 重启软件即可生效。

**手动方式：**
如果你下载了本仓库中的 `.zip` 文件，可以将解压后的文件夹放入灵域智核的插件目录中，重启软件即可识别。

## 🛠️ 当前可用插件

本仓库根目录下的 `.zip` 压缩包即为所有可用插件。随着生态的发展，我们会陆续更新更多实用工具。
